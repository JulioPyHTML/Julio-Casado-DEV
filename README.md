# Julio Enrique Casado Castillo — Portfolio

Portfolio profesional estático para presentar mi perfil como Licenciado en Informática, con enfoque en soporte TI, sistemas Windows, redes básicas y automatización con Python y Excel.

## Sitio publicado

Cuando finalice el primer despliegue, el sitio estará disponible en:

**https://juliopyhtml.github.io/Julio-Casado-DEV/**

## Áreas profesionales

- Soporte técnico, diagnóstico de hardware y software.
- Sistemas Windows 10/11, instalación de controladores y mantenimiento.
- Redes locales: TCP/IP, DHCP, direccionamiento IP y conectividad de DVR.
- Automatización y procesamiento de tareas con Python.
- Excel, fórmulas y VBA.
- Fundamentos de inteligencia artificial y optimización de prompts.

## Proyectos destacados

| Proyecto | Estado | Contenido |
|---|---|---|
| Portfolio personal | Publicado en el repositorio | HTML, CSS y JavaScript |
| Control de cotizaciones Losas Valdez | Prototipo inicial | Documentación funcional y módulo VBA de cálculo |
| Kit de soporte Windows y redes | Kit inicial | Guía y script PowerShell de diagnóstico local |

Los estados describen el alcance real de cada entrega. Los proyectos de Excel y soporte todavía requieren pruebas en equipos y entornos reales antes de considerarse terminados.

## Publicación

El repositorio usa GitHub Actions para publicar el contenido de la raíz del proyecto en GitHub Pages cada vez que se actualiza la rama main. El flujo está definido en .github/workflows/pages.yml.
