# Julio Enrique Casado Castillo — Portfolio

Portfolio personal listo para GitHub Pages.

## Archivos
- `index.html` — página principal.
- `assets/julio-avatar.gif` — avatar animado.

## Publicar en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube `index.html` y la carpeta `assets`.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda y espera la publicación.

Mantén la carpeta `assets` junto a `index.html` para que el avatar se muestre correctamente.
